Print schedule

Prints what's on screen. For a lookahead or one sub's tasks, set the Filter first — a lookahead fits the timeline to its weeks.

Otherwise the whole schedule is fitted to the sheet width and split across pages by rows. Collapsed summaries stay collapsed. Choose “Save as PDF” in your browser's print dialog for a PDF, and set margins to Default.

How it works

Type tasks in the table. Durations are in workdays (5, 5d, 2w); 0 makes a milestone. Indent a task under another to make the one above it a summary.

Predecessors use row numbers: 4 (finish-to-start), 4SS, 4FF+2d, 4SF, 7FS-1d (lead). Use ed or ew for calendar-day lags that run through weekends and holidays, like cure time: 4FS+7ed. Separate several with commas. You can also drag a bar up or down onto another bar to link them.

Typing a date in Start or Finish sets a start/finish-no-earlier-than constraint, like MS Project. Dragging a bar sideways does the same. Clear it in Info.

Other constraints (Info): start/finish no later than, must start on, must finish on. The no-later-than types never move a task; they cap its late dates, so a task pushed past one shows negative float. Must-start/finish pin the task even if its predecessors say otherwise.

Calendar (Settings): pick the workdays and list holidays, one per line; the buttons load US federal or common construction holidays. Every duration, lag and float is counted in workdays on that calendar. One calendar covers the whole project.

Paste from Excel: copy cells and paste into any cell here — columns fill left to right from that cell in table order (Name, Trade, Duration, Start, Finish, Predecessors, Float is skipped, % done). Paste with rows selected (not in a cell) to insert the rows above.

Trade labels who does the work. Use Color by trade and the Filter menus for a sub's tasks or a 2–6 week lookahead; Print prints what's shown.

Status date (in Settings) drives updates: tasks not started yet can't start before the day after it, and unfinished work on in-progress tasks is pushed past it. Tasks that slip show negative float.

Trace highlights the chain of tasks that sets the selected task's start. Info and the bar tooltip also say what drives each start.

Float is total float in workdays; tasks with zero or negative float are critical and shown in red. Summary tasks span their subtasks, with % done weighted by duration, and are never critical themselves; their dates, duration and % can't be typed over.

Baseline: Set baseline saves every task's current dates, and gray bars show them from then on. Re-setting overwrites the old one; Clear removes it. Duplicated tasks start without progress or baseline.

Files: Save writes a .json file that keeps everything. MSP XML exports to MS Project (File › Open there) and Open reads Project XML back in. Check the calendar after an import, since Project calendars carry more detail than this tool uses. CSV is a one-way export for spreadsheets.

Built for a bigger screen

This scheduler is made for a mouse and keyboard on a wide display. It won't work well on a phone.
